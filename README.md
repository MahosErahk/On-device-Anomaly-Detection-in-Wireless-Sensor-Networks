# UV Wireless Sensor Network Anomaly Detection

This repository contains the implementation of a TinyML-based anomaly detection framework for ultraviolet (UV) wireless sensor networks.

## Features

- UV optical channel simulation
- Environmental impairment modeling
- Dataset generation
- Deep learning-based anomaly detection
- Model evaluation
- Demonstration scripts

> 🚧 This repository is currently under active development. The codebase is being refactored from a research prototype into a modular Python project.
